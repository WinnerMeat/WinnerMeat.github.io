《动手学深度学习》预备知识：数据预处理

本文围绕《动手学深度学习》第 2 章“预备知识”中的 2.2 数据预处理 展开，使用 Python、pandas 和 PyTorch 演示如何读取 CSV 数据、处理缺失值、编码类别变量，并将表格数据转换为张量。

适用读者：正在学习 Python、PyTorch 与深度学习基础的初学者。

1. 为什么需要数据预处理？

真实数据通常不会像数学教材中的例子那样整齐。数据文件可能包含缺失值、文本类别、格式不一致的字段，甚至存在无法直接参与数值运算的内容。而深度学习模型通常需要数值化的输入，因此，在把数据交给模型之前，我们往往需要先进行数据预处理。

本节以一个小型房屋数据集为例，字段如下：

  • NumRooms：房间数量，数值型变量；
  • Alley：巷道类型，类别型变量；
  • Price：房屋价格，数值型目标变量。

典型的数据预处理流程可以概括为：

  1. 读取数据：从 CSV 等文件载入原始记录。
  2. 识别字段含义：区分输入特征与预测目标。
  3. 处理缺失值：根据字段类型选择填充、删除或其他策略。
  4. 编码类别变量：将文本类别转换为数值表示。
  5. 转换为张量：将处理后的数值数据转换为 PyTorch Tensor，供后续计算使用。

提醒：预处理方法应根据数据含义和任务目标选择。示例中的均值填充与独热编码是入门方法，并不意味着所有数据都应该这样处理。

2. 读取数据集

2.1 CSV 文件是什么？

CSV（Comma-Separated Values，逗号分隔值）是一种常见的表格数据存储格式。通常每一行表示一条记录，每一列表示一个字段，首行常用于存储列名。

本例会在代码中创建一个名为 house_tiny.csv 的小型数据文件，以保证示例可以独立运行，不依赖外部下载的数据。

这里的 NA 表示原始文件中缺少相应字段的值。使用 pandas.read_csv() 读取文件时，pandas 通常会把这类标记识别为缺失值，并显示为 NaN。

3. 区分输入特征与预测目标

在监督学习中，通常需要把数据拆分为输入特征和目标值：

  • 输入特征（inputs）：提供给模型用于预测的信息；
  • 目标值（outputs）：模型希望预测的结果。

本例将前两列作为输入特征，将最后一列 Price 作为预测目标。pandas 的 iloc 可以按照行列的位置进行索引。

4. 处理缺失值

4.1 缺失值的含义与处理思路

缺失值表示某个记录的字段没有可用观测值。常见原因包括数据采集失败、用户未填写、传感器故障或数据合并时信息缺失等。

常见处理思路包括：

方法核心思想适用时需要考虑的问题
删除删除含有缺失值的行或列可能损失样本或有用特征
填充（插补）用某个合理值替代缺失值填充值会影响数据分布与模型结果
单独建模缺失状态将“是否缺失”作为额外特征需要判断缺失本身是否携带信息

4.2 数值型缺失值：使用均值填充

对于数值型字段，可以根据具体任务使用均值、中位数、固定常数或模型估计值填充。为了与本节的入门示例保持一致，这里使用该列的均值替换缺失值。

NumRooms 中已知的值为 2 和 4，均值为：

$$ \bar{x} = \frac{2+4}{2}=3 $$

使用 pandas 实现：

# 复制一份输入数据，避免修改原始数据
inputs = data.iloc[:, 0:2].copy()

# 仅对数值列使用该列的均值填充缺失值
numeric_columns = inputs.select_dtypes(include="number").columns
inputs[numeric_columns] = inputs[numeric_columns].fillna(
    inputs[numeric_columns].mean()
)

print(inputs)

此时，NumRooms 的缺失值已由均值 3.0 填充，但 Alley 中的缺失值仍然存在，因为它是类别型字段，不适合直接用数值均值填充。

实践注意： 在机器学习项目中，如果数据需要拆分为训练集和验证集，应只使用训练集计算均值、中位数等填充值，再将同一填充值应用到验证集和测试集，避免数据泄漏。

4.3 类别型缺失值：把缺失作为一个类别

Alley 表示巷道类型，是类别型变量。类别值不是具有自然数值大小的测量值，因此不能简单地计算“类别均值”。

一种简单方法是把缺失值作为一个独立类别。pandas 的 get_dummies() 可以将类别列转换为独热编码（One-Hot Encoding）列。参数 dummy_na=True 会为缺失值保留一个类别列。

1
2
3
4

# 将类别型变量转换为独热编码列，并把缺失值作为一个类别
inputs = pd.get_dummies(inputs, dummy_na=True, dtype=int)

print(inputs)

输出示例：

1
2
3
4

   NumRooms  Alley_Pave  Alley_nan
0       3.0           1          0
1       2.0           0          1
2       4.0           0          1
3       3.0           0          1

解释：

  • Alley_Pave = 1 表示该记录的巷道类型为 Pave；
  • Alley_nan = 1 表示该记录的巷道类型缺失；
  • 每一行用相应的 0 和 1 表示所属类别。

这里的列名 Alley_nan 是由 pandas 根据原列名与缺失类别生成的。它是一个普通的特征名称，不代表数值运算中的 NaN 仍然保留在编码结果里。

4.4 删除缺失值的简单示例

虽然本节重点介绍填充，但也可以通过 dropna() 删除含缺失值的记录：

1
2

data_without_missing_rows = data.dropna()
print(data_without_missing_rows)

该方法会删除至少有一个字段缺失的行。本例中每一行至少有一个输入字段缺失，因此删除后可能没有可用记录。真实任务中应先统计缺失比例，再决定是否删除。

5. 将数据转换为 PyTorch 张量

5.1 为什么要转换为张量？

pandas 的 DataFrame 适合读取和整理表格数据；PyTorch Tensor 则是 PyTorch 中进行数值计算与模型训练的核心数据结构。

在转换前，应确保输入数据中的缺失值已按计划处理，并且类别字段已转成数值。完成上述步骤后，输入特征可以转换为浮点张量，目标值也可以转换为浮点张量。

import torch

# 将输入特征转换为 NumPy 数组，再构造 PyTorch 张量
X = torch.tensor(inputs.to_numpy(), dtype=torch.float32)

# 将目标值转换为形状为 (样本数, 1) 的浮点张量
y = torch.tensor(outputs.to_numpy(), dtype=torch.float32).reshape(-1, 1)

print("输入张量 X：")
print(X)
print("X 的形状：", X.shape)

print("\n目标张量 y：")
print(y)

from pathlib import Path

import pandas as pd
import torch


def main():
    # 1. 创建示例 CSV 文件
    data_file = Path("house_tiny.csv")
    csv_content = """NumRooms,Alley,Price
NA,Pave,127500
2,NA,106000
4,NA,178100
NA,NA,140000
"""
    data_file.write_text(csv_content, encoding="utf-8")

    # 2. 读取数据
    data = pd.read_csv(data_file)
    print("原始数据：")
    print(data)

    # 3. 拆分输入特征和预测目标
    inputs = data.iloc[:, 0:2].copy()
    outputs = data.iloc[:, 2].copy()

    # 4. 对数值型输入特征使用列均值填充缺失值
    numeric_columns = inputs.select_dtypes(include="number").columns
    inputs[numeric_columns] = inputs[numeric_columns].fillna(
        inputs[numeric_columns].mean()
    )

    # 5. 对类别型变量进行独热编码，并将缺失值作为一个类别
    inputs = pd.get_dummies(inputs, dummy_na=True, dtype=int)

    print("\n预处理后的输入特征：")
    print(inputs)

    # 6. 将表格数据转换为 PyTorch 张量
    X = torch.tensor(inputs.to_numpy(), dtype=torch.float32)
    y = torch.tensor(outputs.to_numpy(), dtype=torch.float32).reshape(-1, 1)

    print("\n输入张量 X：")
    print(X)
    print("X.shape =", X.shape)

    print("\n目标张量 y：")
    print(y)
    print("y.shape =", y.shape)


if __name__ == "__main__":
    main()

7. 常见问题与注意事项

7.1 NaN 与字符串 "NA" 是一回事吗？

不完全相同。"NA" 是文本；NaN 是常用的缺失值表示之一。读取 CSV 时，pandas 会根据默认规则或自定义参数将某些文本标记识别为缺失值。若某个字段中的 "NA" 本身具有业务含义，应检查并调整读取参数，避免误把有效文本当成缺失值。

7.2 为什么不能给类别变量直接求均值？

类别标签通常只代表不同类别，不具有可进行加减运算的数量意义。例如，把巷道类型编码成 Pave=1、Gravel=2，并不意味着 Gravel 是 Pave 的两倍。对于无自然顺序的类别变量，独热编码是一种常见选择。

7.3 为什么数值型填充和类别型编码要分开处理？

因为它们的语义不同：数值型字段可以考虑均值或中位数等统计量；类别型字段通常需要保留类别身份。混用处理方式可能制造错误的数值含义。

7.4 为什么转换张量前要检查数据？

PyTorch 的张量数值运算要求输入类型与形状符合相应算子的规则。如果 DataFrame 中仍有文本或缺失值，直接转换成浮点张量可能失败，或导致结果不符合预期。因此，转换前应确认数据已数值化，并检查缺失值、数据类型和形状。

7.5 为什么训练集与测试集要使用相同的编码规则？

模型训练和推理阶段的特征列必须保持一致。如果训练数据有 Alley_Pave、Alley_nan 两列，而测试数据经过独立编码后产生了不同列，模型就无法按原有特征顺序正确处理输入。实际项目中应在训练集上拟合预处理规则，并将相同规则应用于验证集、测试集和线上数据。

8. 本节小结

本节介绍了从原始表格数据到 PyTorch 张量的基本流程：

  1. 使用 pandas.read_csv() 读取 CSV 数据；
  2. 使用 iloc 或列名将数据拆分为输入特征和预测目标；
  3. 识别缺失值，并根据字段类型选择合适的处理方法；
  4. 对数值型字段使用均值等统计量填充缺失值；
  5. 使用 pd.get_dummies() 将类别变量转换为独热编码；
  6. 使用 torch.tensor() 将数值数据转换为 PyTorch 张量；
  7. 在实际机器学习流程中，避免数据泄漏，并确保训练与推理阶段的预处理规则一致。

数据预处理并非简单地把所有空值填满、把所有文本变成数字，而是要尽可能保留数据的有效信息，并让数据表示方式符合后续模型的要求。掌握这一流程后，就可以进一步学习数据集划分、批量加载、特征缩放以及模型训练等内容。
