1. 为什么需要自动微分

深度学习训练通常要最小化一个损失函数 \(L(\boldsymbol{\theta})\)，其中 \(\boldsymbol{\theta}\) 是模型参数。优化器需要计算损失对参数的梯度：

\[ \nabla_{\boldsymbol{\theta}}L= \left(\frac{\partial L}{\partial \theta_1}, \frac{\partial L}{\partial \theta_2},\ldots, \frac{\partial L}{\partial \theta_n}\right) \]

当参数数量很多、计算由许多层运算组成时，手工推导并维护全部导数既困难又容易出错。**自动微分（Automatic Differentiation，AD）**通过跟踪程序执行的基本运算，并组合这些运算的局部导数，自动求出目标输出对输入或参数的导数。

自动微分可以帮助我们：

  • 计算损失对模型参数的梯度；
  • 将链式法则应用到复杂、多层的计算；
  • 支持动态控制流，例如条件分支与循环；
  • 为梯度下降及其变体提供参数更新依据；
  • 计算雅可比积及部分高阶导数。

2. 三类求导方法

2.1 符号求导

符号求导根据数学规则直接推导导数表达式。例如：

\[ f(x)=\sin x+0.1x^3,\qquad f'(x)=\cos x+0.3x^2 \]

它的数学含义清晰，但复杂程序中的表达式可能非常庞大。

2.2 数值求导

中心差分用附近的函数值近似导数：

\[ f'(x)\approx\frac{f(x+h)-f(x-h)}{2h} \]

它容易实现，适合验证结果，但会受到步长和浮点舍入误差影响。

2.3 自动微分

自动微分将程序分解为加法、乘法、正弦、矩阵乘法等基本操作，并按各自的微分规则组合导数。它不是对整个函数做简单数值差分，而是根据实际计算路径传播导数。

方法原理优点局限
符号求导推导导数公式解释直观复杂程序难以手工维护
数值求导比较相邻函数值实现简单近似误差，可能需要多次前向计算
自动微分组合基本运算的局部导数适合复杂程序，通常精度较好需要正确管理计算图与梯度

import torch
import math

def f(x):
    return math.sin(x) + 0.1 * x**3

x_value = 0.7

# 手工推导导数后代入
symbolic = math.cos(x_value) + 0.3 * x_value**2

# 中心差分近似
h = 1e-4
numeric = (f(x_value + h) - f(x_value - h)) / (2 * h)

# PyTorch 自动微分
x = torch.tensor(x_value, dtype=torch.float64, requires_grad=True)
y = torch.sin(x) + 0.1 * x**3
y.backward()
automatic = x.grad.item()

print(f"手工公式：{symbolic:.8f}")
print(f"中心差分：{numeric:.8f}")
print(f"自动微分：{automatic:.8f}")

三种结果应当接近。这里的“手工公式”指先用数学方法推导导数，再代入数值；PyTorch 则跟踪张量运算，并在反向阶段计算梯度。

3. 计算图：记录运算依赖

3.1 计算图是什么

计算图（Computational Graph）用节点和有向边表示一次计算：

  • 叶子节点： 输入张量或需要训练的参数；
  • 运算节点： 加法、乘法、激活函数等操作；
  • 中间节点： 前向计算产生的中间结果；
  • 输出节点： 预测值、目标函数或损失。

例如：

\[ u=xw,\qquad L=u+b \]

依赖关系为 \((x,w)\to u=xw\)，再由 \((u,b)\to L=u+b\)。前向阶段计算数值，反向阶段沿相反方向传播梯度。

图 1： 计算图记录输入、中间运算和输出之间的依赖关系。前向计算生成数值，反向传播使用链式法则计算梯度。

3.2 计算图为何重要

对 \(L=xw+b\)，有：

\[ \frac{\partial L}{\partial x}=w,\qquad \frac{\partial L}{\partial w}=x,\qquad \frac{\partial L}{\partial b}=1 \]

复杂表达式中，一个变量可能通过多条路径影响最终输出。计算图保存这些依赖，反向传播会将每条路径的梯度贡献累加。

import torch

x = torch.tensor(2.0, requires_grad=True)
w = torch.tensor(3.0, requires_grad=True)
b = torch.tensor(0.5, requires_grad=True)

u = x * w
loss = u + b

print("u =", u.item())
print("loss =", loss.item())
print("x.requires_grad =", x.requires_grad)
print("loss.grad_fn =", loss.grad_fn)
print("x.is_leaf =", x.is_leaf)
print("u.is_leaf =", u.is_leaf)

grad_fn 的具体名称可能随 PyTorch 版本或运算类型变化。这里的 x、w、b 是叶子张量，u 是由运算生成的非叶子张量。

PyTorch 通常在实际执行前向运算时动态记录当前路径，因此条件分支和循环都可以改变本轮计算图的结构。

4. 前向计算与反向传播

考虑：

\[ u=x^2,\qquad v=u+1,\qquad y=v^2 \]

前向阶段依次计算 \(u,v,y\)。反向阶段使用链式法则：

\[ \frac{dy}{dx}=\frac{dy}{dv}\frac{dv}{du}\frac{du}{dx} =2v\cdot1\cdot2x=4x(x^2+1) \]

当 \(x=2\) 时，\(u=4\)、\(v=5\)、\(y=25\)，所以 \(\frac{dy}{dx}=40\)。

图 2： 反向传播将输出端的梯度逐层传回输入。每个节点根据自身的局部导数，将收到的梯度转换为传给前一节点的梯度。

6.2 计算图通常在反向传播后释放

普通 backward() 通常会释放本次反向传播所需的图中保存信息。若再次对同一输出反向传播，可能出现计算图已释放的错误。一般应重新进行前向计算：

import torch

x = torch.tensor(2.0, requires_grad=True)

for step in range(2):
    x.grad = None
    loss = (x - 5)**2       # 每轮重新构建计算图
    loss.backward()
    print(f"第 {step + 1} 轮：loss={loss.item():.1f}, grad={x.grad.item():.1f}")

只有确实需要重复使用同一张图时才考虑 retain_graph=True；它可能增加内存占用，不应作为默认选项。

6.4 梯度累积与小批量

把多个小批量的梯度累积后再更新参数，可以模拟较大的有效批量。但若希望结果等价于平均损失的梯度，需要对每个小批量的损失按样本数或累积步数进行正确缩放。

7. 向量输出、雅可比矩阵与向量—雅可比积

7.1 雅可比矩阵

当函数输出为向量 \(\mathbf{y}=F(\mathbf{x})\) 时，一阶导数可组织成雅可比矩阵：

\[ J_{ij}=\frac{\partial y_i}{\partial x_j} \]

若输入有 \(n\) 个分量、输出有 \(m\) 个分量，则 \(J\) 的形状为 \(m\times n\)。

图 3： 雅可比矩阵记录各输出分量对各输入分量的导数。反向传播通常只需计算给定输出权重下的向量—雅可比积，无需显式构造整个矩阵。

7.2 向量—雅可比积

给定 \(\mathbf{y}=F(\mathbf{x})\) 和输出侧向量 \(\mathbf{v}\)，自动微分可计算：

\[ \nabla_{\mathbf{x}}(\mathbf{v}^{\mathsf T}\mathbf{y})=J^{\mathsf T}\mathbf{v} \]

9. 用自动微分完成参数优化

考虑一个简单参数估计任务：

\[ L(w)=(w-4)^2,\qquad \frac{dL}{dw}=2(w-4) \]

使用随机梯度下降逐步调整参数：

import torch

# 可训练参数，初始值为 -1
w = torch.nn.Parameter(torch.tensor(-1.0))
optimizer = torch.optim.SGD([w], lr=0.2)

for step in range(8):
    optimizer.zero_grad()       # 1. 清空上一轮梯度
    loss = (w - 4)**2           # 2. 前向计算损失
    loss.backward()             # 3. 自动计算梯度
    optimizer.step()            # 4. 更新参数

    # 重新计算更新后的损失用于记录
    with torch.no_grad():
        updated_loss = (w - 4)**2

    print(
        f"第 {step + 1:02d} 步："
        f"w={w.item():.4f}, "
        f"更新后损失={updated_loss.item():.6f}"
    )

参数会逐渐向 4 靠近，损失也会下降。学习率控制每次更新的幅度；学习率过大可能造成震荡，过小则可能收敛缓慢。

训练循环的基本结构是：前向计算、计算损失、反向传播、清理/管理梯度、更新参数。自动微分负责求梯度，优化器负责根据梯度更新参数，两者不是同一件事。

如需详细学习，可前往《动手学深度学习》研究。
