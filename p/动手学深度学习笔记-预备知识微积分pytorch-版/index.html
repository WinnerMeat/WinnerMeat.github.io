1. 微积分在机器学习中的作用

机器学习模型的训练可以看作一个优化问题：模型根据输入产生预测，再由损失函数衡量预测与目标之间的差距，最后调整参数以减小损失。微积分提供了衡量“参数改变一点点，结果会改变多少”的工具。

例如，假设某个传感器的读数经过校准函数转换：

\[ s(t)=0.5t^2+2t+1 \]

其中 \(t\) 表示输入读数，\(s(t)\) 表示转换后的数值。导数 \(s'(t)\) 描述输入在某个位置附近轻微变化时，输出大约会变化多少。若系统含有多个参数，偏导数分别描述每个参数的影响；将所有偏导数组合起来，就得到梯度。

微积分在模型训练中主要用于：

  1. 分析敏感度： 判断输入或参数的细微变化会造成多大影响。
  2. 处理多参数函数： 分别计算损失对每个参数的偏导数。
  3. 求复合函数的导数： 将多个运算步骤的局部导数连接起来。
  4. 指导优化： 利用梯度方向更新参数，逐步寻找更低的损失值。

2. 导数：从平均变化到瞬时变化

2.1 平均变化率

对于单变量函数 \(y=f(x)\)，当输入从 \(x\) 变为 \(x+h\) 时，平均变化率定义为：

\[ \frac{f(x+h)-f(x)}{h},\qquad h\ne 0 \]

它表示输入区间内，输出变化量与输入变化量的比值。几何上，这是函数曲线上两点连线（割线）的斜率。

2.2 瞬时变化率与导数

若上面的比值在 \(h\) 趋近于 0 时存在极限，就定义函数在 \(x\) 处的导数：

\[ f'(x)=\lim_{h\to 0}\frac{f(x+h)-f(x)}{h} \]

导数也可写作 \(\frac{dy}{dx}\)。它描述函数在某一点附近的瞬时变化率；从几何角度看，导数是该点切线的斜率。

图 1： 当第二个取样点逐渐靠近固定点时，割线斜率趋近于切线斜率；极限值就是该点的导数。

2.3 全新例题：分析校准函数的变化率

考虑函数：

\[ f(x)=0.5x^2+2x+1 \]

使用求导规则可得：

\[ f'(x)=x+2 \]

因此，当 \(x=3\) 时，\(f'(3)=5\)。这表示在 \(x=3\) 附近，输入每增加一个很小的量，函数输出约增加该小量的 5 倍。

可以用有限差分近似导数：

\[ f'(x)\approx \frac{f(x+h)-f(x)}{h} \]

有限差分是数值近似，不是把极限中的 \(h\) 直接设为某个固定小数。步长太大时，近似误差可能明显；步长过小时，又可能受到浮点舍入误差影响。

import torch

def calibration(x):
    """一个用于演示导数的校准函数。"""
    return 0.5 * x**2 + 2 * x + 1

x = torch.tensor(3.0)
h = 1e-4

# 解析导数：f'(x) = x + 2
exact = x + 2

# 用有限差分近似瞬时变化率
finite_difference = (calibration(x + h) - calibration(x)) / h

print("函数值：", calibration(x).item())
print("解析导数：", exact.item())
print("有限差分近似：", finite_difference.item())

2.4 常见求导规则

规则公式示例
常数函数\(\frac{d}{dx}c=0\)\(\frac{d}{dx}8=0\)
幂函数\(\frac{d}{dx}x^n=nx^{n-1}\)\(\frac{d}{dx}x^4=4x^3\)
常数倍\((cf)'=cf'\)\((7x^2)'=14x\)
加减法\((f\pm g)'=f'\pm g'\)\((x^3-x)'=3x^2-1\)
乘积法则\((fg)'=f'g+fg'\)两个可导函数相乘
商法则\((f/g)'=(f'g-fg')/g^2\)要求 \(g\ne0\)
链式法则\((f(g(x)))'=f'(g(x))g'(x)\)复合函数求导

一些常用导数：

\[ \frac{d}{dx}e^x=e^x,\qquad \frac{d}{dx}\ln x=\frac{1}{x}\quad (x>0) \]\[ \frac{d}{dx}\sin x=\cos x,\qquad \frac{d}{dx}\cos x=-\sin x \]

2.5 可导与连续

函数在某点可导，通常可推出它在该点连续；反过来并不成立。以 \(f(x)=|x|\) 为例，函数在 0 处连续，但左导数为 \(-1\)，右导数为 \(1\)，所以它在 0 处没有唯一的普通导数。

机器学习中常见的分段函数也可能存在不可导点。例如 \(\operatorname{ReLU}(x)=\max(0,x)\) 在 0 处不可导。框架会在相关位置采用约定的梯度处理方式，因此理解数学定义有助于正确解释自动求导结果。

3. 偏导数：多变量函数的局部变化

3.1 定义与直觉

当函数依赖多个变量时，例如 \(z=f(x,y)\)，我们可以只改变其中一个变量，并暂时把其他变量视为常数。由此得到偏导数：

\[ \frac{\partial f}{\partial x},\qquad \frac{\partial f}{\partial y} \]

偏导数衡量函数沿某个坐标方向的瞬时变化率。符号 \(\partial\) 用于强调这是多变量函数的偏导。

3.2 全新例题：二维能耗模型

设一个简化的能耗指标为：

\[ E(a,b)=3a^2+ab+2b^2 \]

其中 \(a,b\) 可以理解为两个可调控制量。分别求偏导：

\[ \frac{\partial E}{\partial a}=6a+b,\qquad \frac{\partial E}{\partial b}=a+4b \]

在 \((a,b)=(1,2)\) 处：

\[ \frac{\partial E}{\partial a}=8,\qquad \frac{\partial E}{\partial b}=9 \]

这意味着在该点附近，若只增加 \(a\)，能耗指标的一阶变化率约为 8；若只增加 \(b\)，对应变化率约为 9。

图 2： 在曲面上固定其他变量并沿某个坐标方向移动，可以用相应截线的切线斜率理解偏导数。

3.4 二阶偏导与混合偏导

对一阶偏导数继续求导，可以得到二阶偏导数。例如：

\[ E_{aa}=\frac{\partial^2 E}{\partial a^2}=6,\qquad E_{bb}=\frac{\partial^2 E}{\partial b^2}=4 \]\[ E_{ab}=\frac{\partial^2 E}{\partial b\,\partial a}=1 \]

当函数的二阶偏导数在邻域内连续时，混合偏导数通常满足 \(E_{ab}=E_{ba}\)。二阶偏导数可以帮助描述曲率，并用于分析局部极值和更高阶优化算法。

4. 梯度与方向导数

4.1 梯度的定义

对于可微的标量函数 \(f:\mathbb{R}^n\to\mathbb{R}\)，梯度是所有一阶偏导数组成的向量：

\[ \nabla f(\mathbf{x})= \begin{bmatrix} \frac{\partial f}{\partial x_1}\\ \frac{\partial f}{\partial x_2}\\ \vdots\\ \frac{\partial f}{\partial x_n} \end{bmatrix} \]

沿用上节能耗模型：

\[ \nabla E(a,b)= \begin{bmatrix} 6a+b\\ a+4b \end{bmatrix} \]

在 \((1,2)\) 处，梯度为 \((8,9)^\mathsf{T}\)。

4.2 梯度的几何含义

梯度有三个重要性质：

  1. 增长方向： 当梯度不为零且函数可微时，梯度指向函数局部增长最快的方向。
  2. 最大变化率： 梯度的二范数 \(\|\nabla f\|_2\) 是该点最大方向导数的值。
  3. 等高线关系： 在梯度非零、等高线光滑等适当条件下，梯度垂直于经过该点的等高线。

图 3： 梯度方向对应函数值上升最快的局部方向，梯度模长对应最大方向变化率。

4.3 方向导数

若 \(\mathbf{v}\) 是单位向量，函数沿该方向的方向导数为：

\[ D_{\mathbf{v}}f(\mathbf{x}) =\nabla f(\mathbf{x})^\mathsf{T}\mathbf{v} \]

由柯西—施瓦茨不等式：

\[ -\|\nabla f\|_2 \le D_{\mathbf{v}}f \le \|\nabla f\|_2 \]

当 \(\mathbf{v}\) 与梯度同向时，方向导数最大；当 \(\mathbf{v}\) 与梯度反向时，方向导数最小。梯度下降正是利用这一性质，尝试沿负梯度方向减小目标函数。

4.5 梯度、雅可比矩阵与海森矩阵

当输出是标量时，所有一阶偏导数组成梯度。当函数输出为向量 \(\mathbf{y}=F(\mathbf{x})\) 时，其一阶导数可组织成雅可比矩阵：

\[ J_{ij}=\frac{\partial y_i}{\partial x_j} \]

对标量函数 \(f(\mathbf{x})\)，二阶偏导数可组成海森矩阵：

\[ H_{ij}=\frac{\partial^2 f}{\partial x_i\partial x_j} \]

梯度提供一阶变化信息，雅可比矩阵描述向量函数的局部线性变化，海森矩阵描述二阶曲率信息。三者相关，但用途不同。

5. 链式法则与复合计算

5.1 基本形式

若：

\[ u=g(x),\qquad y=f(u) \]

则复合函数 \(y=f(g(x))\) 的导数满足：

\[ \frac{dy}{dx} =\frac{dy}{du}\frac{du}{dx} =f'(g(x))g'(x) \]

可以把它理解为：输入的微小变化先影响中间变量，再通过后续函数影响最终输出，因此总变化率由每一步的局部变化率相乘得到。

图 4： 链式法则将复合计算的局部导数沿依赖路径相乘；如果输入影响输出的路径不止一条，就需要累加每条路径的贡献。

5.2 全新例题：三角函数复合模型

设：

\[ y=\sin(x^2+1) \]

令 \(u=x^2+1\)，则 \(y=\sin u\)。所以：

\[ \frac{dy}{du}=\cos u,\qquad \frac{du}{dx}=2x \]

根据链式法则：

\[ \frac{dy}{dx}=2x\cos(x^2+1) \]

当 \(x=1\) 时：

\[ \frac{dy}{dx}=2\cos 2\approx -0.8323 \]

5.3 多变量链式法则

若最终结果 \(y=f(u_1,\ldots,u_m)\)，而中间变量 \(u_j\) 又依赖输入 \(x_i\)，则：

\[ \frac{\partial y}{\partial x_i} =\sum_{j=1}^{m} \frac{\partial y}{\partial u_j} \frac{\partial u_j}{\partial x_i} \]

也就是每条依赖路径上的导数相乘，再把各条路径的贡献相加。

例如：

\[ p=x+y,\qquad q=xy,\qquad r=p^2+2q \]

则：

\[ \frac{\partial r}{\partial x} =2p\frac{\partial p}{\partial x} +2\frac{\partial q}{\partial x} =2(x+y)+2y \]\[ \frac{\partial r}{\partial y} =2(x+y)+2x \]

在 \(x=2,y=3\) 时，\(p=5,q=6,r=37\)，因此：

\[ \frac{\partial r}{\partial x}=16,\qquad \frac{\partial r}{\partial y}=14 \]

6. PyTorch 自动求导实战

6.1 基本流程

PyTorch 的自动微分机制会跟踪参与计算的张量操作，并在反向阶段根据链式法则计算梯度。典型流程如下：

  1. 对需要求导的叶子张量设置 requires_grad=True。
  2. 执行前向运算，生成结果或损失。
  3. 对标量结果调用 backward()，或者使用 torch.autograd.grad() 指定需要的导数。
  4. 读取返回值或叶子张量的 .grad。
  5. 进行下一轮计算前，明确是否需要清除已有梯度。

6.2 backward() 和 autograd.grad()

  • backward() 会把计算得到的梯度累加到相关叶子张量的 .grad 属性。
  • torch.autograd.grad() 直接返回指定输出对指定输入的梯度，通常更适合临时计算或数学验证。

对于标量输出 \(L\)，调用 L.backward() 默认相当于对输出使用种子 1。若输出是向量，则需要指定与输出形状一致的 gradient，PyTorch 由此计算向量—雅可比积。

7. 梯度下降：把导数用于优化

7.1 更新公式

设模型参数为 \(\boldsymbol{\theta}\)，损失函数为 \(L(\boldsymbol{\theta})\)，最基本的梯度下降更新规则为：

\[ \boldsymbol{\theta}_{t+1} =\boldsymbol{\theta}_t-\eta\nabla_{\boldsymbol{\theta}}L(\boldsymbol{\theta}_t) \]

其中 \(\eta>0\) 为学习率。负梯度方向在局部一阶近似下是损失下降最快的方向。学习率过大可能使优化震荡甚至发散；学习率过小则可能导致收敛缓慢。

7.2 全新例题：拟合一个目标值

考虑简单目标函数：

\[ L(w)=(w-6)^2 \]

它在 \(w=6\) 处取得最小值 0，导数为：

\[ \frac{dL}{dw}=2(w-6) \]

若初始参数 \(w_0=1\)，学习率 \(\eta=0.1\)，则梯度为 \(-10\)，更新后：

\[ w_1=1-0.1(-10)=2 \]

7.3 使用优化器管理参数更新

在实际项目中，通常使用 torch.nn.Parameter 或 torch.nn.Module 管理参数，再使用优化器完成更新。下面给出一个小型示例：

import torch

# 将待学习参数注册为可训练参数
w = torch.nn.Parameter(torch.tensor(1.0))
optimizer = torch.optim.SGD([w], lr=0.1)

for step in range(3):
    optimizer.zero_grad()       # 清空上一步的梯度
    loss = (w - 6)**2           # 前向计算损失
    loss.backward()             # 计算梯度
    optimizer.step()            # 根据梯度更新参数
    print(f"第 {step + 1} 步：w={w.item():.4f}, loss={loss.item():.4f}")

每一步都会重新计算当前参数对应的损失和梯度。注意，循环中打印的损失是更新前计算的损失，而参数值已经在 optimizer.step() 后更新；如果需要记录更新后的损失，应再做一次前向计算。

8. 常见错误与数值验证

8.1 为什么 .grad 是 None？

常见原因：

  • 张量没有设置 requires_grad=True。
  • 最终输出与目标张量没有计算依赖关系。
  • 运算位于 torch.no_grad() 环境中，或使用 detach() 切断了计算图。
  • 目标是非叶子张量；非叶子张量默认不保留 .grad，需要时可调用 retain_grad()。
  • 使用了 torch.autograd.grad()，但误以为结果会自动写入 .grad。

8.2 数值梯度检查

对可导函数 \(f(x)\)，可以用中心差分近似：

\[ f'(x)\approx\frac{f(x+h)-f(x-h)}{2h} \]

中心差分在很多平滑函数上比单侧差分具有更好的误差阶，但仍然是近似。以下代码比较解析导数、PyTorch 自动微分和中心差分。

import torch

def f(x):
    return torch.sin(x) + 0.1 * x**3

x = torch.tensor(0.7, requires_grad=True)
y = f(x)
y.backward()
autograd_value = x.grad.item()

h = 1e-3
x0 = torch.tensor(0.7)
finite_difference = ((f(x0 + h) - f(x0 - h)) / (2 * h)).item()

# 解析导数：cos(x) + 0.3*x^2
analytic = (torch.cos(x0) + 0.3 * x0**2).item()

print(f"解析导数：{analytic:.6f}")
print(f"自动微分：{autograd_value:.6f}")
print(f"中心差分：{finite_difference:.6f}")

三种结果应当非常接近，但最后几位可能受浮点精度与步长影响。

8.3 排错清单

  1. 先核对公式： 手算一遍偏导数和链式法则，尤其注意复合函数中的内层导数。
  2. 检查张量属性： 需要求导的输入是否设置了 requires_grad=True。
  3. 确认输出形式： 对非标量输出调用 backward() 时是否传入了梯度种子。
  4. 避免梯度意外累加： 每次参数更新前是否清理梯度。
  5. 留意不可导点： 分段函数在折点处可能没有唯一导数。
  6. 检查数值精度： 有限差分步长过大或过小都会引入误差。
  7. 谨慎使用原地操作： 对参与反向传播的张量进行原地修改，可能破坏自动求导所需的中间信息。

8.4 三种求导方法的比较

方法原理优点局限
解析求导按数学规则推导公式结果清楚，便于解释复杂表达式可能难以手推
有限差分用相邻函数值近似极限实现简单，适合检查有截断误差和浮点误差
自动微分对计算图中的基本运算应用导数规则适合复杂程序，通常精度高需要正确跟踪计算图，并消耗一定内存

自动微分不是对整个函数简单地做数值差分，而是组合计算图中各运算的局部导数。
